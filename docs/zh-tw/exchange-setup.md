# 交易所設置

在 [設置頁面](https://your-site.com/trade?settings=1) 填寫交易所的 API 信息，然後點擊 Save 按鈕保存

點擊 `⟳` 按鈕可以測試到交易所的延遲，最好不要超過 150ms，如果超過，可以考慮使用 Windows 伺服器

::: warning
建議開啟 API Key 的 IP 白名單功能，以提高安全等級。
:::

::: danger
一定**不要**開啟 API Key 的轉賬和提現功能。
:::
