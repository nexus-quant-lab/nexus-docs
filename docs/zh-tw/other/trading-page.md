# 持倉與交易記錄

從 **持倉** 和 **交易記錄** 頁面監控你的活躍部位並查看歷史交易。

## 持倉頁面

![持倉頁面](/images/trading/nexusquant-positions.png)

持倉頁面顯示你在所有已連接交易所的當前持倉。

### 總覽卡片

頁面頂部顯示摘要統計：
- **活躍持倉數** — 目前開倉的部位總數
- **未實現盈虧** — 所有部位的浮動損益合計
- **持倉總價值** — 所有部位規模的 USDT 總和

### 持倉表格

每個持倉顯示：

| 欄位 | 說明 |
|------|------|
| 交易對 | 如 BTC/USDT |
| 方向 | 做多或做空 |
| 數量 | 持倉數量 |
| 進場價 | 平均進場價格 |
| 當前價 | 即時市場價格 |
| 未實現盈虧 | 浮動損益 |
| 策略 | 開倉的策略來源（Webhook / 套利） |

### 操作

- **平倉** — 以市價手動關閉持倉
- **重新整理** — 從交易所重新載入持倉資料

::: warning
在此平倉會向交易所發送市價單。建議在市場活躍時段操作以獲得較佳成交價。
:::

## 交易記錄頁面

![交易記錄頁面](/images/trading/nexusquant-trades.png)

交易記錄頁面顯示完整的交易歷史，包含已執行和已平倉的交易。

### 篩選功能

使用篩選列縮小結果範圍：
- **交易對** — 依交易對搜尋
- **策略類型** — 篩選 Webhook、DCA 或套利
- **方向** — 僅顯示買入或賣出
- **日期範圍** — 自訂時間區間

### 交易詳情

每筆交易記錄包含：

| 欄位 | 說明 |
|------|------|
| 時間 | 執行時間戳 |
| 交易對 | 交易對名稱 |
| 方向 | 買入或賣出 |
| 價格 | 成交價格 |
| 數量 | 訂單數量 |
| 手續費 | 交易手續費 |
| 已實現盈虧 | 損益（平倉交易） |
| 策略 | 來源策略 |

### 匯出

交易資料可隨時重新整理。如需詳細交易記錄，請參考交易所原生的交易歷史。
