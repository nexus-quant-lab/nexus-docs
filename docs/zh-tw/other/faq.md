## 交易

### 支援哪些訂單類型？
我們支援市價單、限價單和停損單。

### 支援哪些交易所？
請參閱[交易所設置](/zh-tw/exchange-setup)頁面以獲取完整列表。

## 安全

### 我的 API 金鑰安全嗎？
我們建議啟用 IP 白名單且不啟用提現權限。

### 我該如何報告安全問題？
請通過我們的官方管道聯繫我們。
