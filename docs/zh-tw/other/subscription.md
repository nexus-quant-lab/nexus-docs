# 訂閱方案

NexusQuant 提供免費方案供基礎使用，並提供 **Pro 訂閱** 以解鎖進階功能與更高的交易限制。

![訂閱方案頁面](/images/settings/nexusquant-subscription.png)

## 方案比較

| 功能 | 免費 (Free) | Pro 月訂閱 | Pro 年訂閱 |
|---|------|----------|----------|
| **價格** | $0 | $29 USDT/月 | $290 USDT/年 (省約 17%) |
| **交易所連接** | 1 個 | 無限制 | 無限制 |
| **策略數量** | 每類 1 個 | 無限制 | 無限制 |
| **Webhook 自動化** | 基礎功能 | 完整 (含 SL/TP、範本) | 完整 (含 SL/TP、範本) |
| **資金費率套利** | 僅監控 | 自動執行 | 自動執行 |
| **ahr999 智能定投** | 僅檢視 | 自動執行 | 自動執行 |
| **Telegram 通知** | 基礎通知 | 優先執行通知 | 優先執行通知 |

## 如何訂閱

1. 前往控制台中的 **訂閱** 頁面。
2. 選擇您偏好的方案（月訂閱或年訂閱）。
3. 如果您是由朋友推薦註冊，**10% 優惠** 將自動套用於您的首次付款。
4. 點擊 **加密貨幣付款**（由 NOWPayments 提供支援）。
5. 在付款頁面選擇幣種並發送準確金額。
6. 區塊鏈交易確認後，您的帳號將自動升級為 Pro。

## 支援的付款網路

我們透過 NOWPayments 支援 350+ 種加密貨幣付款，建議使用以下手續費較低的網路：
- **TRC20** (Tron)
- **BEP20** (BNB Smart Chain)
- **Solana**
- **Polygon**

::: tip 安全提醒
發送資金前務必再次檢查錢包地址與網路。NexusQuant 絕不會透過社交軟體主動詢問您的私鑰或要求轉帳到私人地址。
:::

## 推薦折扣
透過推薦連結註冊的新用戶，在首次訂閱付款時可享有 **10% 優惠**。此折扣將在結帳時由系統自動計算並套用。
