# 風險提示

::: danger 重要聲明
加密貨幣交易涉及重大損失風險，並非適合所有投資者。使用 NexusQuant 前請仔細閱讀本頁內容。
:::

## 一般風險

### 市場風險
加密貨幣價格波動劇烈，單日漲跌幅可達 10-50% 甚至更多。過去的表現不代表未來的結果。

### 流動性風險
某些交易對可能流動性不足，特別是小幣種或非尖峰時段。這可能導致市價單產生顯著滑價。

### 槓桿風險
使用槓桿的合約交易會同時放大收益和損失，可能虧損超過初始保證金。資金費率套利雖設計為市場中性策略，但若其中一腿執行失敗仍有風險。

### 技術風險
- 交易所 API 可能出現停機或效能降低
- 網路延遲可能導致訂單執行延遲
- 儘管經過廣泛測試，軟體仍可能存在 bug

### 監管風險
各國對加密貨幣的監管規定不同且持續變化。某些交易所或交易行為在你所在的地區可能受到限制。

## 平台特定風險

### 自動化交易
NexusQuant 根據你設定的策略自動執行交易。策略啟動後：
- 訂單無需手動確認即會下達
- 從訊號產生到執行之間，市場狀況可能已經改變
- 系統中斷可能導致無法及時下單或取消訂單

### API 金鑰安全
雖然 NexusQuant 會加密儲存 API 金鑰且不要求提款權限：
- 你有責任確保自己的交易所帳戶安全
- 在交易所端啟用 IP 白名單以增加安全性
- 為 NexusQuant 使用專用的 API 金鑰，與其他服務分開

### 第三方依賴
NexusQuant 依賴：
- 交易所 API 進行下單和取得市場數據
- 外部數據源進行指標計算（如 ahr999）
- 支付處理商進行訂閱管理

任何第三方服務中斷都可能影響平台功能。

## 風險管理最佳實踐

1. **先用測試網** — 在交易所測試網上測試策略，再使用真實資金
2. **設定止損** — 在 Webhook 策略啟用 SL/TP 限制下行風險
3. **適當控制倉位** — 單筆交易不要冒超出承受能力的風險
4. **定期監控** — 每日檢查儀表板和交易記錄
5. **分散投資** — 不要將所有資金集中在單一策略或交易對
6. **保留儲備金** — 維持足夠的保證金，避免槓桿部位被強制平倉

## 免責聲明

NexusQuant 是交易自動化工具，不提供財務建議、投資推薦或獲利保證。所有交易決策最終由你自行負責。使用 NexusQuant 即表示你理解並接受這些風險。
