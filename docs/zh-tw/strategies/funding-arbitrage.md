# 資金費率套利

資金費率套利是一種**市場中性策略**，透過永續合約的資金費率賺取收益，同時對沖價格風險。

## 運作原理

1. **開立現貨多頭**（買入資產）
2. **開立永續合約空頭**（同等大小、同一資產）
3. **每 8 小時收取資金費率**（當費率為正時）
4. **當機會減少時平倉**

由於同時持有等量的多空部位，價格波動互相抵消 — 你的收益純粹來自資金費率。

## 什麼時候資金費率為正？

當市場**看漲**時，資金費率通常為正 — 交易者願意支付溢價持有永續合約多頭。作為套利者，你透過做空永續合約並用現貨多頭對沖來收取這個溢價。

## 在 NexusQuant 中設定

### 前置條件
- 支援**現貨和永續合約**的交易所（建議 Binance、OKX、Bybit）
- 現貨和合約帳戶中有足夠餘額
- API Key 開啟**現貨 + 合約交易**權限

### 操作步驟

1. 前往 **控制台** → **資金費率套利**
2. 選擇交易對（例如 BTC/USDT）
3. 設定部位大小
4. 配置進場門檻（最低資金費率）
5. 點擊**啟動策略**

### 關鍵參數

| 參數 | 說明 | 建議值 |
|------|------|--------|
| 進場門檻 | 開倉的最低年化資金費率 | > 10% APR |
| 部位大小 | 每組對沖部位的金額 | 依風險承受度 |
| 最大部位數 | 同時持有的套利對數量 | 3-5 |
| 出場門檻 | 費率低於此值時平倉 | < 5% APR |

## 風險提醒

::: warning
雖然這是低風險策略，但**並非零風險**。
:::

- **執行時差**：現貨和合約訂單可能不會在完全相同的時間/價格成交
- **費率反轉**：資金費率可能轉為負值，造成成本
- **爆倉風險**：如果合約保證金不足，空頭部位可能被強制平倉
- **交易所風險**：交易所本身的對手方風險

## 小技巧

- 先用小部位測試整個流程
- 觀察費率趨勢 — 避免在費率下降時進場
- 保留額外保證金在合約帳戶以防爆倉
- 使用手續費較低的交易所以最大化淨收益
