# ahr999 智能定投

智能定投使用 **ahr999 指標**來判斷何時以及買入多少比特幣。不是固定時間固定金額，而是根據比特幣的相對價值動態調整投資金額。

## 什麼是 ahr999？

ahr999 指標衡量比特幣目前價格相對於：
- **200 日定投成本**（如果你每天買入，200 天的平均成本）
- **擬合增長值**（比特幣長期對數增長趨勢）

ahr999 值越低，代表比特幣相對於歷史均值**越便宜**。

## 投資區間

| ahr999 值 | 區間 | 操作 | 倍數 |
|----------|------|------|------|
| < 0.45 | 抄底區間 | 加大買入 | 基礎金額的 3 倍 |
| 0.45 - 1.2 | 定投區間 | 正常買入 | 基礎金額的 1 倍 |
| > 1.2 | 高估區間 | 停止買入 | 0 倍（觀望） |

### 範例

假設你的基礎定投金額是 **每週 $100**：
- ahr999 = 0.3 → 買入 **$300**（抄底區間）
- ahr999 = 0.8 → 買入 **$100**（正常定投區間）
- ahr999 = 1.5 → 買入 **$0**（觀望，市場高估）

## 在 NexusQuant 中設定

### 前置條件
- BTC/USDT 流動性好的交易所（建議 Binance、OKX）
- API Key 開啟**現貨交易**權限
- 明確的定投預算規劃

### 操作步驟

1. 前往 **控制台** → **智能定投**
2. 選擇交易所和交易對（BTC/USDT）
3. 配置參數：

| 參數 | 說明 | 範例 |
|------|------|------|
| 基礎金額 | 正常區間每期投入金額 | $100 |
| 頻率 | 買入頻率 | 每週 / 每日 |
| 抄底倍數 | ahr999 < 0.45 時的倍數 | 3 倍 |
| 定投倍數 | 0.45 ≤ ahr999 ≤ 1.2 時的倍數 | 1 倍 |
| 停買門檻 | ahr999 超過此值時停止買入 | 1.2 |

4. 點擊**啟動策略**

![智能定投設定頁面](/images/strategies/nexusquant-dca-setup.png)

## ahr999 計算方式

平台自動獲取以下數據：
1. **BTC 目前價格** — 從你連接的交易所取得
2. **200 日移動平均成本** — 模擬過去 200 天每日定投的平均成本
3. **擬合增長值** — 基於比特幣歷史對數回歸

ahr999 值在儀表板上即時更新。

## 小技巧

- **保持耐心**：定投是長期策略 — 價值來自數月甚至數年的持續買入
- **不要凌駕指標**：如果 ahr999 顯示停買，相信數據
- **保留現金**：不要把所有資金都投入 — 保留現金等待抄底機會
- **每月檢視**：查看你的平均成本，如果財務狀況改變可以調整基礎金額
