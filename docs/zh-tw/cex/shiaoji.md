## 生產環境

這些是用於現貨帳戶真實交易的 API 金鑰。

### 步驟：

1.  前往 https://www.sinotrade.com.tw 並登入。
2.  確保：
    -   已啟用 2FA
    -   身份驗證已完成
3.  前往 **設定** → **API 管理**
4.  點擊 **建立 API 金鑰**
5.  輸入標籤（例如 `prod-spot`）
6.  完成安全驗證
7.  儲存 **API 金鑰** 和 **密鑰**
8.  建議設定 IP 白名單

------------------------------------------------------------------------

## 注意事項與最佳實踐

-   生產金鑰交易真實資金 --- 請妥善保管。
-   切勿在程式碼儲存庫中暴露 API 金鑰。
-   散戶 (Sino) 不提供公開的測試網用於 API 交易。

::: warning
請勿為 API 金鑰啟用提現權限。
:::
