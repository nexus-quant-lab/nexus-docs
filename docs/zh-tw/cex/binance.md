## 1. 正式生產環境 (實盤幣安 API 金鑰)

這些是用於現貨和合約帳戶實盤交易的真實 API 金鑰。

### 步驟：

1. 前往 https://www.binance.com 並登入。
2. 確認：
    - 已啟用雙重身份驗證 (2FA，如 Google 驗證器 / 簡訊)。
    - 已完成身份認證 (KYC)。
3. 點擊右上角個人資料圖示 → **API 管理**。
4. 點擊 **建立 API**。
5. 輸入標籤名稱 (例如：`prod-spot`、`prod-futures`)。
6. 完成安全驗證。
7. 儲存 **API Key** 和 **Secret** (Secret 僅顯示一次)。
8. 設定權限：
    - 根據需求勾選「啟用現貨及槓桿交易」。
    - 根據需求勾選「啟用合約」。
    - 設定 IP 白名單 (強烈建議)。

## 2. 現貨模擬交易 API 金鑰

幣安模擬交易使用虛擬資金模擬現貨交易。

### 步驟：

1. 登入幣安模擬環境 (https://demo.binance.com)。
2. 進入 **模擬交易** 模式 (透過網頁或 App)。
3. 在模擬交易介面中前往 **API 管理**。
4. 點擊 **建立 API**。
5. 命名 (例如：`demo-spot`)。
6. 完成 2FA 驗證。
7. 儲存 API Key 和 Secret。

------------------------------------------------------------------------

## 3. 合約模擬交易 API 金鑰

合約模擬交易提供 USDⓈ-M 和 COIN-M 合約交易模擬。

### 步驟：

1. 登入幣安模擬交易 (https://www.binance.com)。
2. 切換至 **合約模擬交易**。
3. 前往 **API 管理**。
4. 點擊 **建立 API**。
5. 命名 (例如：`demo-futures`)。
6. 完成驗證。
7. 儲存 API Key 和 Secret。

------------------------------------------------------------------------

## 注意事項與最佳實踐

- 正式金鑰涉及真實資金交易 —— 請妥善保管。
- 模擬金鑰僅適用於模擬交易環境。
- 切勿在程式碼倉庫 (如 GitHub) 中洩露 API Secret。

::: warning 警告
請勿為 API 金鑰開啟「提現」權限。
:::
