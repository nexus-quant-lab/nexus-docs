## 1. 生產環境

這些是用於現貨和合約帳戶真實交易的 API 金鑰。

### 步驟：

1.  前往 https://www.gate.io 並登入。
2.  確保：
    -   已啟用 2FA（Google 驗證器 / 簡訊）
    -   身份驗證已完成
3.  點擊右上角的個人資料圖示 → **API 管理**
4.  點擊 **建立 API 金鑰**
5.  輸入標籤（例如 `prod-spot`、`prod-futures`）
6.  完成安全驗證
7.  儲存 **API 金鑰** 和 **密鑰**（密鑰只顯示一次）
8.  設定權限：
    -   如需要啟用現貨與槓桿交易
    -   如需要啟用合約
    -   建議設定 IP 白名單

------------------------------------------------------------------------

## 2. 測試網

Gate 測試網使用虛擬資金模擬交易。

### 步驟：

1.  前往 https://testnet.gateio.dev
2.  使用您的測試網帳戶登入（如需要請建立一個）
3.  前往 **API 管理**
4.  點擊 **建立 API 金鑰**
5.  命名（例如 `testnet-spot`）
6.  完成 2FA 驗證
7.  儲存 API 金鑰和密鑰

------------------------------------------------------------------------

## 注意事項與最佳實踐

-   生產金鑰交易真實資金 --- 請妥善保管。
-   測試網金鑰僅適用於測試網交易。
-   切勿在程式碼儲存庫中暴露 API 金鑰。

::: warning
請勿為 API 金鑰啟用提現權限。
:::
