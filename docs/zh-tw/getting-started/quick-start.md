# 快速開始

歡迎來到快速開始指南。本頁面將幫助您快速上手。

## 前提條件

在開始之前，請確保您具備：

- 已安裝 Node.js 18+
- 代碼編輯器（推薦 VS Code）
- 基本的命令列知識
