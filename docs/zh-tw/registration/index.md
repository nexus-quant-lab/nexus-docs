# 註冊帳號

## 建立帳號

### 電子郵件註冊

1. 前往 [NexusQuant](https://nexusquant.io) 並點擊 **註冊**
2. 輸入你的**電子郵件地址**
3. 選擇一個**用戶名稱**
4. 設定**密碼**（至少 8 個字元，包含字母和數字）
5. 點擊 **註冊**
6. 檢查信箱收取驗證信，點擊連結啟用帳號

![NexusQuant 註冊頁面](/images/auth/nexusquant-register.png)

::: tip
如果沒有收到驗證信，請檢查垃圾郵件資料夾。驗證信由 NexusQuant 系統發送。
:::

### Google 快速登入

你也可以使用 Google 帳號快速註冊：

![Google 登入按鈕](/images/auth/nexusquant-google-signin.png)

1. 在註冊頁面點擊 **使用 Google 登入**
2. 選擇你的 Google 帳號並授權 NexusQuant
3. 帳號自動建立完成，無需電子郵件驗證

## 推薦註冊

如果你收到現有用戶的推薦連結：

1. 使用推薦連結開啟註冊頁面
2. 推薦碼會自動套用
3. 依照上述步驟完成註冊
4. 首次訂閱 Pro 可享 **九折優惠**

## 帳號安全

- 為 NexusQuant 帳號使用**強度高且獨特的密碼**
- 使用 Google 登入時，確保 Google 帳號已啟用**兩步驟驗證**
- 隨時可從**個人資料**頁面更改密碼
