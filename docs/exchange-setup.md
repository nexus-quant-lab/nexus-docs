# Exchange Setup

Fill in the exchange API information in the [Settings Page](https://your-site.com/trade?settings=1), then click Save to save.

Click the `⟳` button to test the latency to the exchange. It's best to keep it under 150ms. If it exceeds 150ms, consider using a Windows server.

::: warning
It is recommended to enable IP whitelist for your API Key to improve security.
:::

::: danger
Do **NOT** enable transfer or withdrawal functions for your API Key.
:::
