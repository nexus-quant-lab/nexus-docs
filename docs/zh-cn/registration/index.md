# 注册账号

## 创建账号

### 电子邮件注册

1. 前往 [NexusQuant](https://nexusquant.io) 并点击 **注册**
2. 输入你的**电子邮件地址**
3. 选择一个**用户名**
4. 设置**密码**（至少 8 个字符，包含字母和数字）
5. 点击 **注册**
6. 检查邮箱收取验证邮件，点击链接激活账号

![NexusQuant 注册页面](/images/auth/nexusquant-register.png)

::: tip
如果没有收到验证邮件，请检查垃圾邮件文件夹。验证邮件由 NexusQuant 系统发送。
:::

### Google 快速登录

你也可以使用 Google 账号快速注册：

![Google 登录按钮](/images/auth/nexusquant-google-signin.png)

1. 在注册页面点击 **使用 Google 登录**
2. 选择你的 Google 账号并授权 NexusQuant
3. 账号自动创建完成，无需电子邮件验证

## 推荐注册

如果你收到现有用户的推荐链接：

1. 使用推荐链接打开注册页面
2. 推荐码会自动应用
3. 按照上述步骤完成注册
4. 首次订阅 Pro 可享 **九折优惠**

## 账号安全

- 为 NexusQuant 账号使用**强度高且独特的密码**
- 使用 Google 登录时，确保 Google 账号已启用**两步验证**
- 随时可从**个人资料**页面更改密码
