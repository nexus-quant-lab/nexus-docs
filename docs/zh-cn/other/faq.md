# 常见问题

### 我该如何开始？
请参阅[快速开始](/zh-cn/getting-started/quick-start)指南。

### 我该如何设定 API 密钥？

## 交易

### 支持哪些订单类型？
我们支持市价单、限价单和止损单。

### 支持哪些交易所？
请参阅[交易所设置](/zh-cn/exchange-setup)页面以获取完整列表。

## 安全

### 我的 API 密钥安全吗？
我们建议启用 IP 白名单且不启用提现权限。

### 我该如何报告安全问题？
请通过我们的官方渠道联系我们。
