# 持仓与交易记录

从 **持仓** 和 **交易记录** 页面监控你的活跃仓位并查看历史交易。

## 持仓页面

![持仓页面](/images/trading/nexusquant-positions.png)

持仓页面显示你在所有已连接交易所的当前持仓。

### 总览卡片

页面顶部显示摘要统计：
- **活跃持仓数** — 当前开仓的仓位总数
- **未实现盈亏** — 所有仓位的浮动损益合计
- **持仓总价值** — 所有仓位规模的 USDT 总和

### 持仓表格

每个持仓显示：

| 字段 | 说明 |
|------|------|
| 交易对 | 如 BTC/USDT |
| 方向 | 做多或做空 |
| 数量 | 持仓数量 |
| 入场价 | 平均入场价格 |
| 当前价 | 实时市场价格 |
| 未实现盈亏 | 浮动损益 |
| 策略 | 开仓的策略来源（Webhook / 套利） |

### 操作

- **平仓** — 以市价手动关闭持仓
- **刷新** — 从交易所重新加载持仓数据

::: warning
在此平仓会向交易所发送市价单。建议在市场活跃时段操作以获得较好的成交价。
:::

## 交易记录页面

![交易记录页面](/images/trading/nexusquant-trades.png)

交易记录页面显示完整的交易历史，包含已执行和已平仓的交易。

### 筛选功能

使用筛选栏缩小结果范围：
- **交易对** — 按交易对搜索
- **策略类型** — 筛选 Webhook、DCA 或套利
- **方向** — 仅显示买入或卖出
- **日期范围** — 自定义时间区间

### 交易详情

每笔交易记录包含：

| 字段 | 说明 |
|------|------|
| 时间 | 执行时间戳 |
| 交易对 | 交易对名称 |
| 方向 | 买入或卖出 |
| 价格 | 成交价格 |
| 数量 | 订单数量 |
| 手续费 | 交易手续费 |
| 已实现盈亏 | 损益（平仓交易） |
| 策略 | 来源策略 |

### 导出

交易数据可随时刷新。如需详细交易记录，请参考交易所原生的交易历史。
