# 风险提示

::: danger 重要声明
加密货币交易涉及重大损失风险，并非适合所有投资者。使用 NexusQuant 前请仔细阅读本页内容。
:::

## 一般风险

### 市场风险
加密货币价格波动剧烈，单日涨跌幅可达 10-50% 甚至更多。过去的表现不代表未来的结果。

### 流动性风险
某些交易对可能流动性不足，特别是小币种或非高峰时段。这可能导致市价单产生显著滑点。

### 杠杆风险
使用杠杆的合约交易会同时放大收益和损失，可能亏损超过初始保证金。资金费率套利虽设计为市场中性策略，但若其中一腿执行失败仍有风险。

### 技术风险
- 交易所 API 可能出现停机或性能降低
- 网络延迟可能导致订单执行延迟
- 尽管经过广泛测试，软件仍可能存在 bug

### 监管风险
各国对加密货币的监管规定不同且持续变化。某些交易所或交易行为在你所在的地区可能受到限制。

## 平台特定风险

### 自动化交易
NexusQuant 根据你设定的策略自动执行交易。策略启动后：
- 订单无需手动确认即会下达
- 从信号产生到执行之间，市场状况可能已经改变
- 系统中断可能导致无法及时下单或取消订单

### API 密钥安全
虽然 NexusQuant 会加密存储 API 密钥且不要求提款权限：
- 你有责任确保自己的交易所账户安全
- 在交易所端启用 IP 白名单以增加安全性
- 为 NexusQuant 使用专用的 API 密钥，与其他服务分开

### 第三方依赖
NexusQuant 依赖：
- 交易所 API 进行下单和获取市场数据
- 外部数据源进行指标计算（如 ahr999）
- 支付处理商进行订阅管理

任何第三方服务中断都可能影响平台功能。

## 风险管理最佳实践

1. **先用测试网** — 在交易所测试网上测试策略，再使用真实资金
2. **设置止损** — 在 Webhook 策略启用 SL/TP 限制下行风险
3. **适当控制仓位** — 单笔交易不要冒超出承受能力的风险
4. **定期监控** — 每日检查仪表盘和交易记录
5. **分散投资** — 不要将所有资金集中在单一策略或交易对
6. **保留储备金** — 维持足够的保证金，避免杠杆仓位被强制平仓
