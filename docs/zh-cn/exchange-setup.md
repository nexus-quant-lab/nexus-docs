# 交易所设置

在 [设置页面](https://your-site.com/trade?settings=1) 填写交易所的 API 信息，然后点击 Save 按钮保存

点击 `⟳` 按钮可以测试到交易所的延迟，最好不要超过 150ms，如果超过，可以考虑使用 Windows 服务器

::: warning
建议开启 API Key 的 IP 白名单功能，以提高安全等级。
:::

::: danger
一定**不要**开启 API Key 的转账和提现功能。
:::
