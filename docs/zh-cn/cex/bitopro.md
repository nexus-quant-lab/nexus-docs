## 生产环境

这些是用于现货账户真实交易的 API 密钥。

### 步骤：

1.  前往 https://www.bitopro.com 并登录。
2.  确保：
    -   已启用 2FA（Google 身份验证器 / 短信）
    -   身份验证已完成
3.  点击右上角的个人资料图标 → **API 管理**
4.  点击 **创建 API 密钥**
5.  输入标签（例如 `prod-spot`）
6.  完成安全验证
7.  保存 **API 密钥** 和 **密钥**
8.  建议设置 IP 白名单

## 注意事项与最佳实践

-   生产密钥交易真实资金 --- 请妥善保管。
-   切勿在代码仓库中暴露 API 密钥。
-   BitoPro 不提供公开的测试网用于 API 交易。

请勿为 API 密钥启用提现权限。
