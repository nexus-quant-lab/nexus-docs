## 1. 生产环境

这些是用于现货和合约账户真实交易的 API 密钥。

### 步骤：

1.  前往 https://www.htx.com 并登录。
2.  确保：
    -   已启用 2FA（Google 身份验证器 / 短信）
    -   身份验证已完成
3.  点击右上角的个人资料图标 → **API 管理**
4.  点击 **创建 API**
5.  输入标签（例如 `prod-spot`、`prod-futures`）
6.  完成安全验证
7.  保存 **API 密钥** 和 **密钥**（密钥只显示一次）
8.  设置权限：
    -   如需要启用现货与杠杆交易
    -   如需要启用合约
    -   建议设置 IP 白名单

------------------------------------------------------------------------

## 2. 测试网

HTX 测试网使用虚拟资金模拟交易。

### 步骤：

1.  前往 https://testnet.htx.com
2.  使用您的测试网账户登录（如需要请创建一个）
3.  前往 **API 管理**
4.  点击 **创建 API**
5.  命名（例如 `testnet-spot`）
6.  完成 2FA 验证
7.  保存 API 密钥和密钥

------------------------------------------------------------------------

## 注意事项与最佳实践

-   生产密钥交易真实资金 --- 请妥善保管。
-   测试网密钥仅适用于测试网交易。
-   切勿在代码仓库中暴露 API 密钥。

::: warning
请勿为 API 密钥启用提现权限。
:::
