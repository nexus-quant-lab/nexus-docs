# ahr999 智能定投

智能定投使用 **ahr999 指标**来判断何时以及买入多少比特币。不是固定时间固定金额，而是根据比特币的相对价值动态调整投资金额。

## 什么是 ahr999？

ahr999 指标衡量比特币当前价格相对于：
- **200 日定投成本**（如果你每天买入，200 天的平均成本）
- **拟合增长值**（比特币长期对数增长趋势）

ahr999 值越低，代表比特币相对于历史均值**越便宜**。

## 投资区间

| ahr999 值 | 区间 | 操作 | 倍数 |
|----------|------|------|------|
| < 0.45 | 抄底区间 | 加大买入 | 基础金额的 3 倍 |
| 0.45 - 1.2 | 定投区间 | 正常买入 | 基础金额的 1 倍 |
| > 1.2 | 高估区间 | 停止买入 | 0 倍（观望） |

### 示例

假设你的基础定投金额是 **每周 $100**：
- ahr999 = 0.3 → 买入 **$300**（抄底区间）
- ahr999 = 0.8 → 买入 **$100**（正常定投区间）
- ahr999 = 1.5 → 买入 **$0**（观望，市场高估）

## 在 NexusQuant 中设定

### 前置条件
- BTC/USDT 流动性好的交易所（建议 Binance、OKX）
- API Key 开启**现货交易**权限
- 明确的定投预算规划

### 操作步骤

1. 前往 **控制台** → **智能定投**
2. 选择交易所和交易对（BTC/USDT）
3. 配置参数：

| 参数 | 说明 | 示例 |
|------|------|------|
| 基础金额 | 正常区间每期投入金额 | $100 |
| 频率 | 买入频率 | 每周 / 每日 |
| 抄底倍数 | ahr999 < 0.45 时的倍数 | 3 倍 |
| 定投倍数 | 0.45 ≤ ahr999 ≤ 1.2 时的倍数 | 1 倍 |
| 停买门槛 | ahr999 超过此值时停止买入 | 1.2 |

4. 点击**启动策略**

## ahr999 计算方式

平台自动获取以下数据：
1. **BTC 当前价格** — 从你连接的交易所获取
2. **200 日移动平均成本** — 模拟过去 200 天每日定投的平均成本
3. **拟合增长值** — 基于比特币历史对数回归

ahr999 值在仪表板上实时更新。

## 小技巧

- **保持耐心**：定投是长期策略 — 价值来自数月甚至数年的持续买入
- **不要凌驾指标**：如果 ahr999 显示停买，相信数据
- **保留现金**：不要把所有资金都投入 — 保留现金等待抄底机会
- **每月检视**：查看你的平均成本，如果财务状况改变可以调整基础金额
