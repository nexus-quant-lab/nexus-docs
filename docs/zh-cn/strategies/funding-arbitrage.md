# 资金费率套利

资金费率套利是一种**市场中性策略**，通过永续合约的资金费率赚取收益，同时对冲价格风险。

## 运作原理

1. **开立现货多头**（买入资产）
2. **开立永续合约空头**（同等大小、同一资产）
3. **每 8 小时收取资金费率**（当费率为正时）
4. **当机会减少时平仓**

由于同时持有等量的多空仓位，价格波动互相抵消 — 你的收益纯粹来自资金费率。

## 什么时候资金费率为正？

当市场**看涨**时，资金费率通常为正 — 交易者愿意支付溢价持有永续合约多头。作为套利者，你通过做空永续合约并用现货多头对冲来收取这个溢价。

## 在 NexusQuant 中设定

### 前置条件
- 支持**现货和永续合约**的交易所（建议 Binance、OKX、Bybit）
- 现货和合约账户中有足够余额
- API Key 开启**现货 + 合约交易**权限

### 操作步骤

1. 前往 **控制台** → **资金费率套利**
2. 选择交易对（例如 BTC/USDT）
3. 设定仓位大小
4. 配置进场门槛（最低资金费率）
5. 点击**启动策略**

### 关键参数

| 参数 | 说明 | 建议值 |
|------|------|--------|
| 进场门槛 | 开仓的最低年化资金费率 | > 10% APR |
| 仓位大小 | 每组对冲仓位的金额 | 依风险承受度 |
| 最大仓位数 | 同时持有的套利对数量 | 3-5 |
| 出场门槛 | 费率低于此值时平仓 | < 5% APR |

## 风险提醒

::: warning
虽然这是低风险策略，但**并非零风险**。
:::

- **执行时差**：现货和合约订单可能不会在完全相同的时间/价格成交
- **费率反转**：资金费率可能转为负值，造成成本
- **爆仓风险**：如果合约保证金不足，空头仓位可能被强制平仓
- **交易所风险**：交易所本身的对手方风险

## 小技巧

- 先用小仓位测试整个流程
- 观察费率趋势 — 避免在费率下降时进场
- 保留额外保证金在合约账户以防爆仓
- 使用手续费较低的交易所以最大化净收益
